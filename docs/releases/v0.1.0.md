## Included

Vertical workspace switching, clock and date, optional CPU/RAM/battery widgets,
a Windows theme toggle, and a tray menu with Windows autostart controls.

The installer configures GlazeWM, backs up its original configuration, stops Zebar,
and adds Native Sidebar to the Start menu and Windows Installed apps.
See the [installation guide](https://github.com/muc-martin/glazewm-sidebar#install)
for configuration changes and uninstall instructions.
