# Changelog

## 0.1.0 — unreleased

- Native 28-pixel sidebar with smaller text and a fixed, lighter slate palette.
- Single-click workspace switching; only occupied/current workspaces are shown.
- Removed occupancy dots; hand cursor only over clickable workspace buttons.
- Notification-area icon with startup toggle and exit; Start menu launcher.
- Removed experimental Shift-click move, scroll switching and context menu.
- Event-driven GlazeWM connection with automatic reconnect and single-instance guard.
- Per-user ZIP installer, Windows sign-in startup and GlazeWM/Zebar integration.
- Configuration backups, guarded upgrades and reversible uninstall.
- Portable CMake build, offline dependency, installer tests and CI artifact packaging.

No public release has been published.
